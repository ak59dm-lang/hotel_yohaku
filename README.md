静寂と自分自身に向き合う「余白」の時間をテーマにした架空のホテルブランドのWebサイトです。

##  コンセプト
「何もしない贅沢」を届けるためのシンプルなデザインと、心地よい操作性（マインドフルネスなWeb体験）の両立。

##  主な機能・こだわり
- **デザイン:** フォント（Cormorant Garamond / Noto Serif JP）や配色で静けさを表現
- **インタラクション:** 
  - スクロール駆動によるフッターの質感変化
  - Swiperを用いた直感的なスライダー
  - レスポンシブ対応のドロワーメニュー
- **予約機能:** 簡易計算ロジック付きの予約シミュレーション（Modal表示）

##  使用技術
- HTML5 / CSS3 (Flexbox, Grid, CSS Variables)
- JavaScript (Vanilla JS / GSAP / Swiper)
- VS Code / Prettier
